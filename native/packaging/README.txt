Noggin Knockers 2 — native Windows and macOS edition

This release runs the game directly on your operating system. It uses the
original game art and sound with a 100 Hz gameplay core derived from the
open-source 3DO port.

Windows: unzip the complete folder and run NogginKnockers2.exe.
macOS: open Noggin Knockers 2.app. Keep the app bundle intact.

Controls:
  Player 1: WASD to move; J/K for specials (Z/X also work).
  Player 2: arrow keys to move; keypad 1/2 for specials
            (Right Ctrl/Right Shift also work).
  Menus and one-player mode also accept arrows and Enter/Space.
  P pauses; Esc or Backspace cancels or returns to the title.
  Ctrl+B hides the match background; F11 toggles fullscreen.
  Gamepad: D-pad to move, A/B for specials, Start to pause, Back to cancel.

In Options, HD Upscale switches between Classic (off, the default) and an
edge-aware Scale4x rendering of the original artwork. The choice is saved.
Use a larger window or fullscreen to see the full benefit of HD mode.

The game uses local files in assets/. Keep that folder beside the Windows
executable or inside the macOS app bundle. If you move the executable alone,
the game will not find its art or audio.

Source code and license notices are included in Source/ and LICENSES/.
