# Noggin Knockers 2 — native desktop port

A native SDL2 port of Noggin Knockers 2 for macOS and Windows. It runs without
the DOS executable and includes the original game's artwork and audio. The
Options screen has an HD Upscale toggle; the game also supports keyboard and
gamepad play.

Download the macOS and Windows bundles from this repository's Releases page.
See [native/README.md](native/README.md) for controls, build instructions,
verification, and provenance.

The original DOS executables and `.VOL` files are not tracked here. The
runtime assets in `native/assets/` were generated from a game copy. The
artwork and audio remain copyrighted by their original creators; see
[native/assets/README.md](native/assets/README.md) for details. The portable
game core and tools carry their own license notices in `native/core/` and
`native/tools/nog2vol/`.
